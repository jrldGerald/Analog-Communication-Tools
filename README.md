ANALOG COMMUNICATION TOOLS 

A C++ and SFML-based tool designed to visualize and analyze Modulated signals. This project focuses on the mathematical implementation of signal modulation, real-world noise interference, and signal recovery.

PROJECT FOCUS: 
The primary goal of this tool is to demonstrate how a low-frequency message signal is superimposed onto a high-frequency carrier wave.

KEY FEATURES (In Development):
Signal Generation: Real-time rendering of carrier waves being modulated by message signals.
Noise Simulation: Adding stochastic noise to the transmission channel to simulate real-world interference.
Signal Filtering: Implementing methods to isolate the modulated signal from noise and recover the original message.
Interactive Parameters: Future support for real-time adjustment of Carrier Frequency and Modulation Index.

TECH STACK
Language: C++
Graphics: SFML (Simple and Fast Multimedia Library)
Version Control: Git/GitHub
